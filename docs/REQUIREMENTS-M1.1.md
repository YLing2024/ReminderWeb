# ReminderWeb M1.1 修正单（验收中发现的问题）

> 依据：负责人按需求书 §6 逐屏截图比对后发现的偏差。逐条修，每条都要能被肉眼验证。

## A. 卡片底部日期带文字被截断（真 bug）

**现象**：手机档 2 列时，农历条目的底带显示 `丙午(2026) 腊月 初四 星...`、`丙午(2026) 十月 二十星...` —— 尾部「星期X」被省略号截掉。
**要求**：
- 底带文字**任何宽度下都不得出现省略号**；优先使用上游的**短格式**（参照 `CalendarUtil.formatLunarDateShort` / `getLunarMonthDayLabel` 的口径，如 `腊月初四`），再拼星期；
- 底带内文字用 `clamp()` 自适应字号 + 单行不换行；若仍放不下，缩短的是**农历前缀**而不是「星期X」；
- 公历条目维持 `YYYY-MM-DD 星期X`。
**验收**：390px 宽下截屏，所有卡片底带完整可读。

## B. 卡片顶部色带高度随标题长度变化 → 网格错位（真 bug）

**现象**：同一分组内「入职周年 还有」与「结婚纪念日 还有」两张卡的顶带高度不同，导致同一行卡片上下错位（见平板档截图）。
**要求**：
- 顶带**固定高度**（与上游一致，约 40–44px），文案单行、超长省略号；
- 同一行卡片的顶带、主体、底带的基线必须完全对齐（用固定高度的三区结构，不要让内容撑高卡片）。
**验收**：平板档 3 列下同排卡片上下边缘像素级对齐。

## C. ≥600px 时左下「视图切换」按钮缺失

**现象**：手机档左下角有切换卡片/列表的圆形按钮，平板 / 桌面档看不到。
**要求**：三档断点下都必须能切换卡片 / 列表两种布局；桌面端可以是左下悬浮按钮，也可以是页面内的分段控件，但**必须可达且可见**。

## D. 日期输入显示格式

**现象**：新增页日期框显示 `10/07/2026`（受浏览器 locale 影响），上游为 `2026-10-07`。
**要求**：显示为 `YYYY-MM-DD`（给日期控件设 `lang="zh-CN"` 或自绘只读显示 + 原生选择器），公历 / 农历切换后显示口径清晰（农历显示如 `腊月初四`）。

## E. 顶栏品牌字标未用手写体

**现象**：现为衬线斜体兜底，与上游的手写体字标观感差距明显。
**要求**：自托管一款开源手写体（SIL OFL，例如 Great Vibes / Dancing Script 之类）的 **woff2 子集**到仓库内（只含 `Reminder` 所需字形即可），本地加载、不走 CDN；字体文件缺失时仍回退衬线斜体（不得白屏或报错）。字体许可与来源写进「关于」页的开源许可列表。

## F. 次要项（顺手）

- 新增页的「重复」「提醒设置」行当前带填充底色，上游是素底 + 右侧箭头 + 值；改为素底 + 细分隔线。
- 底带文字颜色对比度不足的情况（浅色标签色）要保证可读（≥4.5:1）。

## 铁律（同需求书 §11）

小步多次 `git commit`（conventional commits）；禁止 `git push`、建分支、`rebase`/`reset --hard`/`merge`；禁止 `systemctl`/`kill`/`pkill`；只写 `/root/proj/ReminderWeb/**`（可只读 `/tmp/Reminder-ref`、`ref-shots`）；命令带 `timeout`；不出现真实域名/IP/密钥。完成后运行 `npm run build`、`npm test`、`npm run lint` 并给出真实输出摘要。
